Forecasts how many people watch Grand Theft Auto VI live on Twitch in each hour of its release day (19 Nov 2026, UTC), as five quantiles per hour. It learns the launch-day shape from past rolling-midnight launches: the day's curve as a ratio to the first hour's print, conditioned on how big that first hour was, blending a log-log regression with the median of the most similar first hours.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
